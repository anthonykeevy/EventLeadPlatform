# Handoff Validation Checklist

## Completion Note Quality

- [ ] Summary is accurate and concise
- [ ] All files changed are listed
- [ ] Change types are correct (created/modified/deleted)
- [ ] Each AC has verification status
- [ ] Evidence is specific (not vague)
- [ ] Test commands and outputs are included
- [ ] Manual UAT steps are clear

## Documentation Completeness

- [ ] Completion note created at correct path
- [ ] QA notes created (if insights exist)
- [ ] LESSONS-LEARNED.md updated
- [ ] Out-of-scope items documented with routing

## Handoff Readiness

- [ ] Recommended next step is clear
- [ ] No unresolved blockers (or blockers documented)
- [ ] Human can verify without developer assistance
