# UAT Handoff Validation Checklist

## Summary Accuracy

- [ ] UAT result is correct (PASS/FAIL)
- [ ] Step counts are accurate
- [ ] Defect count matches results file
- [ ] Out-of-scope count matches results file

## Status Update

- [ ] TASK-PLAN.md or STATUS.md is updated
- [ ] Task status is correct (HumanDone/FailedUAT)
- [ ] UATCompletedAt is set
- [ ] Results file is linked

## Routing

- [ ] Next agent is correctly identified
- [ ] If FAIL: defect list is included
- [ ] If PASS: retrospective recommended

## Memory

- [ ] Automation opportunities recorded
- [ ] Failure patterns recorded (if applicable)
