# Story 6.4.4.1 Judge Prompts

## Purpose

Use these prompts for the AC-10 `rubric_v2` baseline re-judge. The judge package is generated by `backend/tests/form_ai_eval/judge_pack.py` and contains `rubric_v2.md`, `judge-input-batch.md`, and `judge-output-template.json`.

Each judge output must set `rubric_version` to `rubric_v2` and must populate `judge_model_version` with the exact model/version shown in the Cursor session.

## Shared Instructions

Apply these instructions in all three judge sessions:

- Judge only the anonymised package content.
- Use `rubric_v2.md` as the scoring authority.
- Return JSON matching `judge-output-template.json`.
- Identify at least one weakness per row before scoring.
- Do not compare `rubric_v2` scores to historical `rubric_v1` outputs.

## Claude 4.7 Primary Judge

Required judge slot: `claude`

Required model: Claude 4.7. Record the exact Cursor model/version in `judge_model_version` (for example, `claude-4.7-sonnet-20260315` when that is the available pinned version).

Prompt:

```text
You are the Claude 4.7 primary judge for Story 6.4.4.1.

Use the attached judge package:
- rubric_v2.md
- judge-input-batch.md
- judge-output-template.json

Score each row against rubric_v2 only. Identify at least one weakness per row before scoring. Return only valid JSON matching judge-output-template.json.
Set judge_model to "claude" and judge_model_version to the exact model/version shown in this Cursor session.
```
