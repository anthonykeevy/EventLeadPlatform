## Summary of Changes

Integrated Grid Layout rendering into UniversalFieldShell. When a component has `gridLayout` configuration (either at component level or from global defaults), it now renders using CSS Grid instead of the default Object Layout system. This uses the utilities created in T01 (`generateGridStyles`, `getObjectGridArea`) to compute the grid container styles and position each object within the grid.

## Detailed Changes

### UniversalFieldShell.tsx

1. **New Imports** (line 13):
   - Added `GridLayoutConfig` type import
   - Added `generateGridStyles`, `getObjectGridArea` utility imports from `gridLayoutUtils.ts`

2. **New Helper Function: `getEffectiveGridLayout()`** (lines 117-168):
   - Resolves effective grid layout from component override → global default → null
   - Merges partial configurations with system defaults
   - Only returns a grid config when `cellAssignments` exist (otherwise falls back to Object Layout)

3. **New Render Function: `renderWithGridLayout()`** (lines 396-518):
   - Generates CSS Grid container styles using `generateGridStyles()`
   - Positions each visible object using `getObjectGridArea()` for `gridRow`/`gridColumn`
   - Skips objects not assigned to any cell
   - Handles `ObjectFeatureHost` wrapping for objects with features
   - Includes devLogger calls for debugging

4. **Integration in Main Render Path** (lines 635-656):
   - Added `effectiveGridLayout` memoized computation
   - Modified `content` useMemo to check for grid layout first
   - When `effectiveGridLayout` is present, uses `renderWithGridLayout()`
   - Falls back to existing Object Layout rendering when no grid layout configured
